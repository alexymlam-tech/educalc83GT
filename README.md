# CW-83 EDU Smart Calc Platform (fx-83GT CW / fx-85GT CW Simulator)

**CW-83 EDU Smart Calc Platform** is a zero-dependency, single-file browser simulator developed for secondary school mathematics education, interactive whiteboard projection, and student self-study. It emulates the workflow, menu hierarchy, and tactile button sequences of the **fx-83GT CW / fx-85GT CW (ClassWiz CW Series)** calculator, without using proprietary trademarks, copyrighted logos, or manufacturer artwork.

---

## 🌟 What's New (Changelog)
- **ClassWiz CW Workflow**: Features the `HOME` 5-app launcher, circular D-pad with `OK` & `BACK`, `CATALOG`, `TOOLS`, and `FORMAT` menus.
- **2D Equation Engine**: Full 2D Natural Textbook AST engine for navigating fractions, roots, and powers.
- **Math Box**: Probability simulations (Dice, Coin) and visual tools.
- **Pastel Color Themes**: Includes Sakura Pink, Matte Black, Arctic White, and Cobalt Blue.

---

## 🔬 Mathematical Capabilities
- **Natural Textbook Display**: Proper fractions, surds, powers, etc.
- **Modes**:
    - **Calculate (`COMP`)**: Arithmetic, trig, prime factorization, etc.
    - **Statistics (`STAT`)**: 1-Var/2-Var data with regressions.
    - **Table (`TABLE`)**: Side-by-side `f(x)` and `g(x)` with 2D editing.
    - **Ratio (`RATIO`)**: Solves $A : B = X : D$.
    - **Math Box**: Dice Roll, Coin Toss, Number Line, Unit Circle.
