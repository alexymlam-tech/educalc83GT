# CalcX: GT CW Scientific Calculator Simulator

A browser-based, single-file educational scientific calculator simulator inspired by the **fx-83GT CW / fx-85GT CW** series. Designed for modern classroom mathematics teaching.

## Features
- **CW Series Workflow**: HOME 5-App grid, circular D-Pad, CATALOG, and TOOLS menu.
- **Interactive Drills**: Step-by-step button sequence training for exam preparation.
- **Math Box**: Includes Dice Roll, Coin Toss, and Unit Circle modules.
- **Self-Contained**: Single HTML file deployment for instant classroom access.

## Deployment
1. Rename your simulator file to index.html.
2. Host on GitHub Pages (Settings → Pages → Select branch).
3. Embed into Google Sites or LMS using the Embed code feature.
